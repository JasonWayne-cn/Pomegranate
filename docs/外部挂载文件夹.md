# 外部挂载文件夹

> 功能：把磁盘上的一个或多个文件夹直接挂载进 Pomegranate，不复制文件；外部
> `.md` / `.txt` / PDF / Word / Excel / CSV 会进入全文搜索、标签、双链/反链索引。
> 文本文件可写回原文件；PDF / Word / Excel 只做单向抽取，影子笔记可编辑但不会覆盖二进制原文件。

---

## 1. 设计原则

外部文件始终是**唯一数据源**：

- 文件内容不搬家，仍保存在原目录；
- 数据库中为每个外部文件建立一条**影子笔记**（`notes.storage_kind = 'external'`），
  保存标题、正文镜像、相对路径、mtime、size、hash；
- 影子笔记复用现有 `notes.id`，因此 FTS5、`note_tags`、`note_links`、AI/RAG、
  MCP、反链面板等能力无需第二套实现。

```
外部文件（磁盘，真实内容）
        │ 读取 / 写回
        ▼
影子笔记 notes（storage_kind='external'）
        ├─ notes_fts      → 全文搜索
        ├─ note_tags      → 标签
        └─ note_links     → 双链 / 反链
```

## 2. 数据库变更（Schema v78）

迁移位置：`src-tauri/src/database/schema.rs`，`SCHEMA_VERSION = 78`。

### 新增表 `external_mounts`

| 字段 | 说明 |
|------|------|
| `id` | 主键 |
| `name` | 显示名称 |
| `root_path` | 挂载根目录（canonical 路径，唯一） |
| `root_folder_id` | 对应的镜像根文件夹 |
| `read_only` | 只读挂载：不写回原文件 |
| `index_enabled` | 是否后台自动扫描 |
| `daily_mode` | 日记识别开关（预留） |
| `scan_interval` | 轮询间隔（秒，默认 10） |
| `sync_types` | 按类别开关同步的 JSON：`{"text":true,"pdf":true,"word":true,"sheet":true}` |
| `created_at` / `last_scan_at` | 时间戳 |

### `notes` 新增列

| 字段 | 说明 |
|------|------|
| `storage_kind` | `'db'`（普通笔记）/ `'external'`（外部影子笔记） |
| `mount_id` | 所属挂载点，`ON DELETE CASCADE` |
| `ext_rel_path` | 相对挂载根的 POSIX 路径，如 `日记/2026-10-23.md` |
| `ext_mtime` / `ext_size` / `ext_hash` | 原文件指纹，用于增量扫描（二进制文件是二进制哈希） |
| `ext_indexed_hash` | 上次抽取写入正文时的哈希，用于判断影子笔记是否被用户编辑过 |
| `ext_indexed_at` | 上次抽取时间 |
| `ext_stale` | 原文件已更新但影子笔记有本地编辑，未自动覆盖 |
| `ext_index_status` | `ok` / `failed` / `stale` / `scanned` / `encrypted` |
| `ext_index_error` | 抽取失败原因 |
| `ext_missing` | 源文件是否已消失 |

唯一索引：

```sql
CREATE UNIQUE INDEX idx_notes_mount_rel
  ON notes(mount_id, ext_rel_path)
  WHERE mount_id IS NOT NULL AND is_deleted = 0;
```

### `folders` 新增列

| 字段 | 说明 |
|------|------|
| `mount_id` | 所属挂载点 |
| `ext_rel_path` | 相对挂载根的目录路径 |

外部目录树会镜像成普通文件夹，因此原有的文件夹列表、按文件夹筛选、拖拽排序 UI 可直接复用。

## 3. 后端模块

### 3.1 数据访问层

文件：`src-tauri/src/database/mounts.rs`

主要方法：

- `create_external_mount` / `list_external_mounts` / `get_external_mount_by_id`
- `delete_external_mount`：删除索引，磁盘文件不动
- `detach_external_mount`：影子笔记转成普通本地笔记
- `ensure_external_folder`：按相对目录创建/复用镜像文件夹链
- `find_external_note` / `upsert_external_note`
- `mark_external_missing_except`：本轮未见的文件标记 `ext_missing = 1`
- `list_external_entries`：前端文件树数据
- `get_external_note_meta`：读取挂载根、绝对路径、只读状态
- `update_external_note_cache`：外部变更/写回后刷新缓存

### 3.2 业务逻辑层

文件：`src-tauri/src/services/mount.rs`

- **添加挂载**：校验目录存在、禁止磁盘根目录、禁止嵌套/重叠挂载
- **递归扫描**：忽略 `.git`、`.obsidian`、`.trash`、`node_modules` 等目录
- **增量策略**：
  - 已存在且 `size + mtime` 未变 → 跳过读文件
  - 变化时读取内容、计算 SHA-256、更新影子笔记
  - 新路径查不到影子笔记时，用 `size + mtime` 匹配"磁盘上已不存在的旧路径笔记"：
    命中即认定是外部移动/归档，沿用原 note id，更新 `ext_rel_path` 与镜像文件夹，
    标签、双链、历史版本不丢失
  - 扫描结束后清理没有笔记也没有子文件夹的镜像文件夹，让目录树与磁盘一致
- **标签**：解析 frontmatter `tags` + 正文行内 `#标签`，写入 `note_tags`
- **双链**：调用 `rebuild_note_links_from_content`
- **打开**：优先读磁盘最新内容并同步缓存
- **保存**：`mtime` 冲突检测后写回磁盘，再刷新缓存
- **后台监听**：每 5 秒检查一次，各挂载点按自己的 `scan_interval` 执行
- **事件**：
  - `mount:scan-progress`：扫描进度
  - `external:changed`：外部内容发生变化
  - `db:external-changed`：触发前端列表刷新

### 3.3 Command 层

文件：`src-tauri/src/commands/mount.rs`

| Command | 说明 |
|---------|------|
| `mount_add` | 新增挂载点，并动态放行 asset 协议目录 |
| `mount_list` | 列出全部挂载点及文件数/缺失数 |
| `mount_remove` | `detach=false` 删除索引；`detach=true` 转本地笔记 |
| `mount_scan` | 手动增量扫描，推送进度事件 |
| `mount_list_entries` | 返回挂载内文件条目 |
| `mount_open_file` | 读盘并返回最新内容 |
| `mount_save_file` | 写回磁盘并更新索引 |

注册与启动位置：`src-tauri/src/lib.rs`

- `generate_handler!` 中注册上述 Commands
- setup 阶段为已有挂载点补放 asset 协议范围
- 启动 `run_mount_watch_loop` 后台轮询

## 5. 各项能力的实际行为

### 支持的文件类型

| 类型 | 扩展名 | 正文来源 | 是否写回原文件 |
|------|--------|----------|----------------|
| 文本 | `md` / `markdown` / `txt` / `text` | 原文件内容 | `md` 可写回；`txt` 不写回 |
| PDF | `pdf` | pdf-extract → 修复 → PDFium 兜底 | 否 |
| Word | `docx` / `doc` | 解析 `word/document.xml`；`.doc` 先转换 | 否 |
| 表格 | `xlsx` / `xls` / `xlsm` / `xlsb` / `ods` / `csv` / `tsv` | calamine → GFM 表格 | 否 |

### 全文搜索

影子笔记直接写入 `notes`，`notes_fts` 触发器自动同步 `title / fts_body`。
因此外部文件会出现在：

- 搜索页
- AI RAG 检索
- MCP `search_notes`
- 知识图谱/反链相关查询

### 标签

- frontmatter `tags: [a, b]`
- 正文 `#工作`、`#工作/周报` 等
- 外部内容变化时会整体重建该笔记的标签关联

### 双链 / 反链

- 内部笔记写 `[[外部笔记标题]]` 可正常解析
- 外部笔记引用内部笔记也会建立 `note_links`
- 目标文件尚未扫描入库时链接暂时无法解析，扫描完成后会重建

### 读写

- **文本文件（`.md`）**：可写挂载保存后会调用既有 `write_back_source_md` 写回原文件
- **只读挂载**：文本文件 `source_file_type = NULL`，不会触发写回；UI 会提示只读
- **`.txt`**：会索引，但沿用现有写回逻辑（仅 `md`），不会自动写回
- **PDF / Word / Excel / CSV**：
  - 原文件不被修改；影子笔记正文是抽取结果（PDF/Word 文本、Excel/CSV 表格 Markdown）
  - 影子笔记**可编辑**，编辑只保存在数据库，不会写回二进制原文件
  - `mount_save_file` 对二进制文档直接拒绝，避免把抽取文本覆盖进原文件
  - 预览：PDF 用内置 iframe；Word 用系统默认应用打开原文件；表格正文本身就是 Markdown 表格

### 原文件更新检测（陈旧判定）

每个影子笔记保存两组指纹：

| 指纹 | 含义 |
|------|------|
| `ext_mtime` / `ext_size` / `ext_hash` | 原文件当前版本 |
| `ext_indexed_hash` | 上次抽取写入正文时的正文哈希 |

打开/扫描时：

```
原文件 mtime/size 是否变化？
├─ 否 → 直接使用缓存
└─ 是 → 影子笔记是否被编辑过？(content_hash != ext_indexed_hash)
    ├─ 未编辑 → 自动重新抽取，更新缓存
    └─ 已编辑 → 标记 ext_stale=1，保留本地编辑，等待用户选择
```

UI：

- 挂载页文件树显示「原文件已更新」标签与 `RefreshCw` 图标
- 编辑器打开时弹出通知，提供「重新抽取」按钮
- 「重新抽取」会覆盖影子笔记的本地编辑（`mount_reextract`）

抽取失败时：

- 保留已有正文
- 记录 `ext_index_status = 'failed'` 与 `ext_index_error`
- 记录本轮原文件指纹，避免后台每 10 秒重复解析坏文件
- 用户可手动「重新抽取」重试

### 缺失文件

文件被外部删除时：

- 影子笔记**不删除**
- 标记 `ext_missing = 1`
- 前端显示缺失数量与警告图标
- 文件恢复后重新扫描会自动清除标记

### 卸载

| 方式 | 行为 |
|------|------|
| 移除索引 | 删除影子笔记和镜像文件夹，磁盘文件保留 |
| 转为本地笔记 | 保留影子笔记内容，清空挂载关联，变成普通本地笔记 |

## 6. 隔离与安全

| 项目 | 处理 |
|------|------|
| WebDAV 同步 | `sync_v1` manifest/push 只处理 `storage_kind = 'db'`，外部笔记不参与同步 |
| 笔记加密 | 外部笔记禁止加密（磁盘源文件仍是明文） |
| 文件夹操作 | 镜像文件夹禁止在普通 UI 中改名/移动/删除 |
| 路径校验 | 挂载根 canonicalize；拒绝磁盘根；拒绝嵌套/重叠挂载 |
| 相对路径 | 读取前拒绝绝对路径和包含 `..` 的异常路径 |
| 资源访问 | 挂载时动态 `allow_directory`，放行 asset 协议 |

## 7. 使用方式

### 启动开发模式

```bash
pnpm tauri dev
```

开发服务器端口以实际输出为准（当前配置为 `http://127.0.0.1:2010`）。

### 挂载一个文件夹

1. 打开「文档」面板
2. 点击标题栏的「外部目录设置」按钮（同步文件夹 + 齿轮图标）
3. 点击「添加外部目录」
4. 选择磁盘文件夹
5. 确认名称，按需开启「只读」
6. 点击「挂载并扫描」

首次扫描会自动建立索引；之后后台按 `scan_interval` 增量扫描。

### 修改同步设置

1. 在挂载点卡片的操作区点击「设置」
2. 修改「同步间隔（秒）」，范围 2–3600
3. 按类别开关同步：Markdown/纯文本、PDF、Word、Excel/CSV
4. 每个类型旁显示已索引数量
5. 可同时调整只读、自动索引、显示名称
6. 点击「保存」

- 后台调度器每 5 秒巡检一次
- 每个挂载点只有距上次扫描 ≥ 自己的间隔时才真正扫描
- 关闭某类型后：不再扫描该类型的新文件；已索引文档保留并标记「已暂停」
- 重新开启某类型：清空暂停状态，下一次扫描恢复索引
- 关闭「自动索引」只暂停后台轮询，仍可手动「扫描」

### 文件列表状态与大小

文件树每个文件右侧显示：

- 原文件大小（B / KB / MB / GB）
- 同步状态：`已同步` / `待同步` / `失败` / `缺失` / `已暂停`
- 本地编辑过的影子笔记额外显示 `本地已编辑`

顶部支持状态筛选：全部 / 已同步 / 待同步 / 失败 / 缺失 / 暂停。
文件树固定高度并启用虚拟滚动，避免长列表撑破页面。

### 文件类型图标

挂载文件树和文档目录树按文件类型显示彩色徽章：

| 类型 | 图标 |
|------|------|
| Markdown | `M↓` 青色 |
| 纯文本 | `TXT` 灰色 |
| PDF | `PDF` 红色 |
| Word | `W` 蓝色 |
| Excel / CSV | `X` 绿色 |

缺失、抽取失败、原文件已更新会在文件名旁显示对应标签。

### 浏览与打开

- 在挂载点卡片点击「浏览」查看文件树
- 点击文件会读取磁盘最新内容并打开 `/notes/:id`
- 外部笔记同时也会出现在普通「文档」列表和对应镜像文件夹中

### 手动刷新

- 单个挂载点：「扫描」/「重新扫描」
- 挂载点列表：「刷新」

### 移除

点击「移除」后选择：

- **转为本地笔记**：保留内容
- **移除索引**：只清理数据库索引

## 8. 已知限制

1. **改名/移动**：`size + mtime` 未变的移动/改名会沿用原 note id 并修正目录结构；
   若归档时同时改了内容，仍按“删除 + 新建”处理，原笔记的标签/反链不会迁移。
2. **脏编辑器 + 二进制文档**：影子笔记有未保存修改时，原文件更新会标记 stale，不会自动覆盖；
   但文本文件的写回仍可能在保存时覆盖外部修改。
3. **`.txt` 不写回**：可搜索、可编辑数据库副本，但不会同步回磁盘。
4. **二进制文档单向同步**：PDF / Word / Excel 的编辑只保存在影子笔记，不会回写原文件。
5. **Word 抽取**：`.docx` 只抽纯文本（段落），不保留富文本格式；`.doc` 需要本机 LibreOffice / Office / WPS。
6. **扫描件 PDF**：当前依赖 PDF 文本层，扫描件会抽取失败；OCR 需另行触发。
7. **表格**：正文沿用每表最多 500 行的限制，完整数据仍在原文件。
8. **日记识别**：`daily_mode` 字段与开关已预留，尚未实现自动标记。
9. **资源路径**：已放行 asset 协议，但未做外部图片相对路径到 asset URL 的内容级重写。
10. **旧 `folder_watch`**：与挂载功能存在语义重叠；若监听目录同时被挂载，
    建议只保留一种方式，避免文件夹归属被移动。

## 9. 排错

| 现象 | 排查 |
|------|------|
| 添加时提示目录重叠 | 检查是否已挂载父目录/子目录；嵌套挂载被禁止 |
| 扫描后搜索不到 | 确认扩展名在支持列表内，且文件非空 / 抽取未失败 |
| 外部图片不显示 | 确认挂载已成功添加（asset scope 在添加时放行）；重启后启动阶段也会补放 |
| PDF 抽取失败 | 扫描件 / 加密 / 字体编码问题；先用 Acrobat 或 Chrome 另存为可搜索 PDF |
| Word 抽取失败 | `.doc` 需要 LibreOffice / Office / WPS；`.docx` 可能是损坏的 zip |
| Excel 抽取失败 | 文件为空、格式不受支持或损坏；支持 xlsx/xls/xlsm/xlsb/ods/csv/tsv |
| 文件树显示「原文件已更新」 | 原文件变了且影子笔记有本地编辑；打开笔记点「重新抽取」或保留本地内容 |
| 文件树显示「抽取失败」 | 查看 `ext_index_error`；修复原文件后点「重新抽取」 |
| 保存提示“外部文件已被修改” | `mount_save_file` 的 mtime 冲突检测；重新打开文件确认最新内容 |
| 文件缺失但笔记还在 | 这是预期行为，`ext_missing = 1`，恢复文件后重新扫描即可 |
| 文件夹无法重命名/删除 | 镜像文件夹受保护，请在「外部目录」页操作挂载点 |
