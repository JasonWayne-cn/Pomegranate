> 创建：2026-11-23

> 本仓基线：Pomegranate 2.2.0（schema 89，分支 `main`）

## 1. 目标

V3.5.0 不追 UI 换皮，聚焦 **更新可靠性、数据安全、同步正确性** 三类回移：

- 更新包：下载/续传/换源/验签/跨重启恢复全部下沉到 Rust，前端只做显示。
- 用户数据：任何配置改写、导入、同步修复都不得造成不可逆丢失。
- 同步：修复 manifest 悬空、同天重复日记、凭据丢失等已知缺陷，补文件夹级同步。

## 3. 阶段技术要点

### P1 更新器 Rust 化

**现状问题**（本仓 `src/hooks/useUpdateChecker.ts` + `UpdateModal.tsx`）：
前端持有 `Update` 实例并调用 `download()`，与 KB 改造前的缺陷一致——并发检查各开一路下载、无断点续传、字节只在内存、`install()` 不验签。

**改造**：
1. 新增 `src-tauri/src/services/updater_download.rs`：
   - `UpdaterState`（`Mutex<Inner>` + 操作队列 + 文件锁），`.manage()` 注册。
   - 操作：`check/start/pause/cancel/install`，状态 `idle/checking/available/downloading/paused/verifying/ready/installing/error`。
   - `.part` 断点续传（Range）、同源重试 3 次、换源；`<app_cache_dir>/updates/meta.json` 跨重启恢复。
   - 下载完成与安装前各验签一次（`minisign-verify` + 配置公钥）。
   - 每 250ms 发 `updater://state` 事件（完整快照）。
2. 新增 `commands/updater.rs`（6 个命令）并在 `lib.rs` 注册 + `.manage(UpdaterState::default())`。
3. 前端：新增 `UpdaterSnapshot` 类型与 `updaterApi`；`useUpdateChecker` 改为订阅事件 + 调命令；`UpdateBadge/UpdateModal` 适配新字段（可暂停/取消、显示速度与来源）；`UpdaterProvider` 保持不变。
4. 下载源：主地址取 `update.json` 的 URL；备源按 POM 发布布局配置（GitHub releases / Gitee release），认不出布局只用主地址。
5. 移动端保持现有 `mobile_update` 逻辑不变。

**风险**：Win7 构建需确认 `minisign-verify` / reqwest rustls 无新 API 依赖；安装前验签依赖 `tauri.conf.json` 的 `pubkey` 存在。

### P2 MCP 配置安全写入

在 `commands/mcp.rs` 的安装/合并逻辑上补齐：
- JSON 解析失败 → 返回错误，不写文件。
- 写前备份 `<config>.bak-<时间戳>`。
- 写临时文件 + `rename` 原子替换。
- `mcpServers` 已有条目不覆盖其它 server，仅更新目标项。
- CLAUDE.md 模板中 MCP 条目名区分开发版/正式版。

### P3 同步体系回移

- 逐文件对比 `sync_v1/{manifest,pull,push,backend_*,conflicts,note_md,mod}.rs`。
- 优先修复（低风险）：悬空条目自动修复、同一天日记去重、编辑同步源凭据沿用、导入/整包拉取暂停 HTTP MCP。
- 新增 `folder_sync.rs`（空文件夹/改名/删除/排序/颜色）与 `content_sync.rs`（闪卡/复习/提示词/模板）。
- **schema 映射**：KB 迁移 v68–v73 需重编号为本仓 90+；每项单独迁移 + 测试。

### P4 回收站与统计口径

- `trash.rs` 增加「删除满 30 天自动永久删除」，启动/定时触发，可配置。
- 统计统一：字数与编辑器状态栏同口径；标签计数、首页笔记数排除回收站/隐藏/临时/日记。

### P5 设置配置备份

- 参考 `src/lib/settingsBackup.ts`：`uiPrefs / appConfig / aiModels / syncBackends / asr` 五类，导出为 `.kbconfig`（复用本仓 `config-share` 的 bundle 格式），导入走现有弹窗。
- 密钥类字段不导出；只对本机有意义的键列入排除名单。
