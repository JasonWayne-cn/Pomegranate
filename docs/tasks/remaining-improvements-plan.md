## 3. 优先级与建议批次

| 批次 | 内容 | 理由 |
|------|------|------|
| R0 数据安全 | 同步数据安全批次（备份 3 份、数据目录/升级失败保护）、folder sync 前置调查 | 数据不可逆损失风险最高 |
| R1 高频功能 | AI 会话置顶/分叉/提问导航、页面行为小功能（行距、搜索三列、今日待办）、Windows 升级钩子 | 用户感知强、改动可控 |
| R2 同步扩展 | folder_sync + content_sync（manifest/schema 变更） | 工作量大，需单独回归 |
| R3 配置/窗口/打包 | 设置备份、窗口位置记忆、安装包模板/CI 钉版本 | 工程与体验完善 |
| R4 独立功能 | 思维导图、移动端 v4、手机当主机 | 独立立项，避免与主线混杂 |

## 4. 下一份建议细化的方案

1. **`sync-remaining-plan.md`**：folder/content sync + 数据安全批次（与 `lan-sync-plan.md` L0 衔接）。
2. **`ai-assistant-plan.md`**：会话置顶/克隆/分叉/续写 + 工具轮次修复。
3. **`packaging-release-plan.md`**：Rust 钉版本、Windows 升级钩子、kb-mcp 让位。
4. **`settings-backup-plan.md`**：把 P5 从条目升级为详细设计。
5. **`page-behavior-plan.md`**：页面行为小功能清单与逐页验收。

## 5. 通用验收门禁

```bash
cd src-tauri && cargo check && cargo test --lib
npx tsc --noEmit
pnpm test
pnpm build
```

- 涉及 schema：单独迁移 + 迁移测试 + 旧库升级测试。
- 涉及同步：manifest 兼容（旧版本忽略新字段）、两端收敛测试。
- 涉及 Windows 安装：升级安装、卸载、AI 会话不被中断。
- 涉及移动端：真机回归清单。
