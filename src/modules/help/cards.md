# 卡片复习

卡片复习使用间隔重复算法，帮助你把文档中的知识点转化为长期记忆。

## 快速上手

1. 从文档中创建卡片，正面写问题，背面写答案；
2. 进入「卡片复习」开始今日复习；
3. 按记忆程度评分，系统会安排下次复习时间；
4. 通过统计查看学习进度。

## 评分说明

- **忘记**：需要尽快再次复习。
- **困难**：间隔增长较慢。
- **良好**：按正常间隔推进。
- **简单**：间隔增长较快。

## 常见问题

**卡片和文档是什么关系？**
卡片可以独立存在，也可以关联到来源文档，便于回到上下文。

**可以导入现成卡片吗？**
支持通过 Markdown 或批量导入创建卡片，具体格式见导入页面说明。
