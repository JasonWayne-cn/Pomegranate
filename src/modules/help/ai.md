# AI 问答

AI 问答模块把本地笔记作为上下文，帮助你总结、提问和整理知识。

## 快速上手

1. 先在设置中配置 AI 模型与 API Key；
2. 进入「AI 问答」，选择模型；
3. 直接提问，或在提问时引用指定笔记；
4. AI 的回复可以保存为新笔记，便于沉淀。

## 核心能力

- **笔记问答**：基于当前笔记或全库检索结果回答问题。
- **总结与改写**：对长文进行摘要、提取要点或调整语气。
- **多模型**：支持 OpenAI 兼容协议、Ollama、LM Studio 等服务。
- **语音输入**：配置语音识别后，可以直接口述问题。

## 参数说明

| 参数 | 说明 |
| --- | --- |
| 温度 | 越高越发散，越低越稳定 |
| 上下文消息条数 | 携带多少轮历史对话 |
| 流式输出 | 边生成边显示，减少等待感 |
| 系统提示词 | 定义助手的角色与回答风格 |

## 常见问题

**提示连接失败？**
请检查模型地址、API Key 和网络；本地模型需确认服务已启动。

**AI 会把我笔记上传吗？**
只会发送当前请求所需的上下文到你所配置的模型服务，请自行评估服务商的隐私政策。

**如何更换模型？**
在设置页「AI 能力中心」中添加或编辑模型，然后在对话顶部选择。
