# 扩展包

扩展包（Engine Pack）用于按需加载不内置在主程序中的能力，目前提供 PPT 生成引擎。

## 安装

1. 打开侧边栏「扩展包」。
2. 点击「安装扩展包」，选择本地 zip。
3. 查看预检信息（版本、文件数、体积、权限、兼容性）后确认安装。
4. 安装完成后可启用/禁用、校验完整性、查看版本或卸载。
5. 点击「版本」可查看已安装版本，并离线回滚到旧版本。

## 签名

扩展包支持可选的 Ed25519 签名。带签名的包需要主程序配置
`PPT_EXTENSION_PUBLIC_KEY`（base64 32 字节公钥）；未配置时安装会被拒绝。
未签名的本地 zip 仍可安装，但只依赖文件哈希与来源信任。

## PPT 生成

安装并启用 PPT 扩展后，侧边栏会出现「PPT 生成」入口：

- 支持选择多个文档、日记与挂载文件。
- 可选择版式模板（layouts）、图表模板（charts）与是否使用原生图表。
- 先生成大纲，可在「大纲确认」步骤调整页序、标题与要点，再开始渲染。
- 生成完成后可打开 PPT、工程目录，或在「历史作业」中重试、删除、导出诊断包。

## 注意

- 扩展包会运行本地 Python 引擎，请只安装可信来源的 zip。
- 未安装扩展时，主程序不会加载任何 PPT 引擎，也不会创建相关进程。
- 中间工程文件默认保留在应用数据目录的 `ppt-workspace` 下，便于排查和重跑。
- 引擎日志写入作业目录的 `logs/engine.log`；诊断包不包含文档正文。
