# 日记

日记模块按日期组织内容，适合写工作日志、每日复盘或随手记录。

## 快速上手

1. 点击左侧「日记」进入月历视图；
2. 点击日期即可打开或创建当天日记；
3. 使用「今天」按钮快速回到当天；
4. 日记本质上也是笔记，可使用标签、搜索和双向链接。

## 常用操作

- **自动创建**：开启后，进入日记模块时会自动创建当天日记。
- **日期格式**：标题日期支持多种显示格式，可在配置中切换。
- **默认模板**：可以为每天自动带入固定的结构，例如「今日完成 / 遇到的问题 / 明日计划」。
- **周数显示**：需要按周复盘时，可在月历中显示周数。

## 存储

日记正文保存在本地数据库中。若配置了日记 Markdown 输出目录，可在此基础上生成或同步 `.md` 文件。

## 常见问题

**找不到昨天的日记？**
在月历中点击对应日期即可打开；也可以使用全局搜索按标题查找。

**如何批量回顾？**
使用「文档关系」查看日记之间的链接，或在搜索中按日期关键词筛选。

## 相关设置

- 本抽屉：常规（自动创建、日期格式、默认模板）、存储位置（日记 Markdown 输出目录）。
- 编辑器排版：与文档共用，可在文档配置抽屉的「编辑器排版」中调整。
