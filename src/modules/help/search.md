# 搜索

搜索模块用于在全部笔记、标签和附件中快速定位内容。

## 快速上手

1. 点击左侧「搜索」，或按 `Ctrl + K` 打开命令面板；
2. 输入关键词，结果会实时更新；
3. 使用筛选器按文件夹、标签、时间范围缩小结果；
4. 点击结果直接跳转到对应笔记。

## 搜索范围

- **标题**：匹配笔记标题，速度最快。
- **正文**：匹配正文内容，适合找回具体段落。
- **标签**：按标签筛选相关笔记。
- **全部**：综合以上来源并按相关度排序。

## 使用技巧

- 多个关键词用空格分隔，可获得更精确的结果。
- 需要精确匹配时，使用引号包裹短语。
- 搜索结果默认按相关度排序，也可以切换为最近更新。
- 搜索历史会保留最近若干条，便于重复查找。

## 常见问题

**搜索不到刚写的内容？**
请确认笔记已保存。若启用了全文索引，索引可能需要短暂时间更新。

**可以搜索附件内容吗？**
可以搜索附件名称与关联笔记；附件正文内容取决于是否启用了 OCR。
