# 文档关系

文档关系把文档之间的双向链接可视化为网络，帮助你发现文档结构。

## 使用方法

1. 在文档中使用 `[[文档标题]]` 建立双向链接；
2. 在文档面板点击图谱图标，查看当前文件夹或全库的文档关系；
3. 点击节点跳转到对应文档；
4. 使用缩放、拖拽和布局切换聚焦某个主题；
5. 点击「返回文档」回到文档列表。

## 阅读建议

- 节点大小通常反映连接数量，连接密集处是文档枢纽。
- 孤立节点表示还没有建立关联，可以考虑补充链接。
- 限定文件夹范围时，范围外的关联文档会以虚线弱化显示。
- 过大的关系图会降低可读性，建议结合文件夹范围查看。

## 常见问题

**为什么有些链接没有显示？**
请确认目标文档存在，且链接标题与文档标题一致。
