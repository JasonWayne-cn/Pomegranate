# 文档

文档模块是应用的核心创作区，用于创建、编辑和归档 Markdown 文档。除了普通文档，还支持白板与思维导图两种特殊视图。

## 快速上手

1. 点击左侧「文档」进入文档列表；
2. 使用顶部工具栏或 `Ctrl + N` 新建文档；
3. 在编辑器中直接输入内容，应用会按设定的间隔自动保存；
4. 使用文件夹与标签组织文档，便于后续检索。

## 编辑与保存

- **所见即所得**模式下，工具栏提供标题、加粗、列表、表格、代码块等常用格式。
- **Markdown 源码**模式适合精确控制语法，可在「配置 → 默认编辑模式」中切换默认值。
- 内容会自动保存；也可以使用编辑器内的手动保存快捷键。
- 删除文档会先进入回收站，可在回收站中恢复。

## 白板与思维导图

- 白板本质是 `note_type = whiteboard` 的特殊文档，适合画流程、整理思路。
- 思维导图可以通过独立窗口打开，便于与主界面并排查看。
- 两者都会作为普通文档出现在列表中，可继续使用标签与文件夹管理。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl + N` | 新建文档 |
| `Ctrl + K` | 打开命令面板 |
| `F11` | 切换专注模式 |
| `Alt + ← / →` | 历史后退 / 前进 |
| `Shift + F1` | 打开当前模块使用说明 |

## 常见问题

**文档保存到哪里？**
文档正文保存在本地 SQLite 数据库中，附件与图片按应用数据目录管理。

**误删了文档怎么办？**
删除的文档会进入「回收站」，在回收站中可以恢复；超过保留期限后才会被清理。

**如何把文档导出为文件？**
在文档的更多操作中选择导出 Markdown 或 HTML；批量导入导出位于全局设置页。

## 相关设置

- 「外部目录设置」：挂载磁盘文件夹、同步间隔、只读/自动索引、文件类型、手动扫描。
- 「历史版本」：文档历史快照与清理。
- 「常规」：自动保存延迟、默认排序、字数统计、导入、导出、OCR、附件清理。
- 「编辑器排版」：字体、字号、行距、阅读列宽、纸张观感、背景纹理、首行缩进；同时作用于文档与日记编辑器。
- 全局设置页：主题与外观（颜色、背景图）等全局选项。
