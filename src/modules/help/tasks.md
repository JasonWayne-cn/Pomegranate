# 待办

待办模块用于管理任务、设置提醒和跟踪完成情况。

## 快速上手

1. 点击左侧「待办」进入任务列表；
2. 在输入框中快速创建任务；
3. 为任务设置截止时间、优先级和重复规则；
4. 完成的任务会归档，可在筛选器中重新显示。

## 核心能力

- **优先级**：低 / 中 / 高，用于排序和视觉区分。
- **提醒**：全天任务会在默认提醒时间提醒；紧急任务可触发独立提醒窗口。
- **重复任务**：支持每天、每周、每月等规则。
- **智能识别**：在文档正文中识别任务语法，并转换为待办。
- **视图**：支持列表与日历视图，便于按时间安排。

## 常见问题

**为什么没有收到提醒？**
请确认任务已设置提醒时间，并检查系统通知权限与提醒声音配置。

**删除的任务能恢复吗？**
任务删除后可在回收站中查找并恢复。

**如何批量调整？**
在列表中使用多选后统一修改优先级、截止时间或标签。

## 相关设置

- 本抽屉：常规（默认提醒时间、显示已完成、默认优先级、重复规则）、提醒声音、智能识别。
- 任务模板统一在全局模板管理中维护。
- 设置页「个性设置」：紧急提醒窗口等应用级提醒设置。
