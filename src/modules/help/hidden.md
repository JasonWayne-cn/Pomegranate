# 隐藏文档

隐藏文档用于存放需要 PIN 保护的私密文档。

## 使用方法

1. 首次使用先设置 PIN；
2. 将文档标记为隐藏，或在隐藏文档中新建；
3. 再次进入时需要输入 PIN 解锁；
4. 会话解锁有有效期，超时后需要重新验证。

## 注意事项

- PIN 用于本地访问控制，请妥善保管。
- 忘记 PIN 可能导致隐藏文档无法访问。
- 隐藏文档不会被普通搜索结果直接展示。

## 常见问题

**可以修改 PIN 吗？**
可以，在隐藏文档的设置中验证旧 PIN 后修改。

## 相关设置

- 本抽屉「隐藏 PIN」面板：启用、修改或清除 PIN。
- 会话解锁时长由应用在每次进入隐藏文档时重新验证。
