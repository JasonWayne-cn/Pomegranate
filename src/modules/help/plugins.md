# 插件

插件系统用于扩展应用能力，支持侧边栏入口、命令和设置页。

## 使用方法

1. 进入「插件」查看已安装插件；
2. 启用或禁用插件；
3. 查看插件声明的权限与命令；
4. 插件注册的侧边栏入口会出现在左侧导航中。

## 安全提示

- 安装前确认插件来源可信。
- 插件声明的文件、网络等权限会在详情中展示。
- 不需要的插件建议禁用或卸载，减少资源占用。

## 常见问题

**插件安装后没有出现入口？**
请确认插件已启用，并检查插件是否声明了侧边栏贡献项。

## 插件设置

- 本抽屉「插件设置」：显示插件注册的设置页 Tab，可直接在抽屉内修改。
- 插件管理：安装、启用、查看权限与命令，仍在「插件」模块中完成。
